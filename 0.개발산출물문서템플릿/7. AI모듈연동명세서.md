# AI 모듈 연동 명세서

## 1. 기술 스택

- **AI Framework**: LangChain
- **API 서버**: FastAPI (REST API, SSE 스트리밍)
- **Vector DB**: FAISS 또는 Chroma
- **LLM**: OpenAI / Gemini / Groq / Upstage 등 (사용 모델 명시)
- **관측**: LangSmith (선택)

## 2. 프로젝트 구조

```
ai-module/
├── src/
│   ├── api/           # FastAPI 서버
│   ├── chains/        # LangChain 체인
│   ├── core/          # 핵심 로직
│   └── utils/         # 유틸리티
├── requirements.txt
└── Dockerfile
```

## 3. 환경 설정

```env
OPENAI_API_KEY=
LANGCHAIN_API_KEY=
DATABASE_URL=
```

## 4. 주요 API

### 4.1 채팅 API
- **POST** `/chat/invoke`
- **POST** `/chat/stream`

### 4.2 문서 처리 API
- **POST** `/upload-document`
- **POST** `/process-document`

### 4.3 퀴즈 생성 API
- **POST** `/generate-quiz`

## 5. RAG 시스템

### 5.1 문서 처리
1. 파일 로드
2. 텍스트 분할
3. 임베딩 생성
4. 벡터 저장

### 5.2 질의응답
1. 질문 임베딩
2. 유사 문서 검색
3. 컨텍스트 생성
4. LLM 응답 생성

## 6. 벡터 DB 설정

- **FAISS 인덱스**: IndexFlatL2
- **임베딩 모델**: text-embedding-3-small
- **청크 크기**: 1000자
- **오버랩**: 200자

## 7. Backend 연동

- HTTP 통신
- 에러 처리
- 타임아웃 설정
- 내부 인증: Backend → AI Module 호출 시 인증 방식 (AI Module은 외부에 직접 노출하지 않음)

## 8. 지원 파일 형식

- PDF
- DOCX  
- TXT

## 9. AI 보안

> 점검·조치 결과는 `9. 보안점검서.md` 4장에 기록합니다. (OWASP LLM Applications Top 10 참고)

- **Prompt Injection 대응**: 시스템 프롬프트 분리, 사용자 입력 길이 제한, 출력 검증
- **데이터 격리**: 사용자별 문서/벡터 컬렉션 분리 (타 사용자 문서 검색 방지)
- **비용·자원 보호**: 요청 크기/횟수 제한, 타임아웃
- **키 관리**: LLM API Key는 환경변수로만 주입, 로그 출력 금지
