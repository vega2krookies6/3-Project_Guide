# Frontend 개발 명세서

## 1. 기술 스택

- **Framework**: React 19.3.x
- **언어**: JavaScript
- **라우팅**: React Router
- **상태 관리**: Zustand
- **스타일링**: Tailwind CSS
- **빌드**: Vite

## 2. 프로젝트 구조

```
frontend/
├── src/
│   ├── components/     # 컴포넌트
│   ├── pages/         # 페이지
│   ├── services/      # API 서비스
│   ├── store/         # Zustand 스토어 (authStore, chatStore …)
│   └── utils/         # 유틸리티
├── package.json
└── Dockerfile
```

## 3. 환경 설정

```env
VITE_API_URL=
```

> `VITE_` 접두사 변수는 **빌드 결과물에 그대로 노출**됩니다. API 키·비밀번호를 넣지 않습니다.
> AI 모듈은 Backend를 통해서만 호출하며, 브라우저에서 직접 호출하지 않습니다.

## 6. 상태 관리

| 스토어 | 파일 | 상태 | 액션 |
|--------|------|------|------|
| useAuthStore | `store/authStore.js` | user, token, isAuthenticated | login, logout |
| useChatStore | `store/chatStore.js` | messages, isLoading | addMessage, appendToken, clear |
| use{업무}Store | `store/{업무}Store.js` | items, loading | |

```javascript
// store/authStore.js
import { create } from 'zustand';

export const useAuthStore = create((set) => ({
  user: null,
  token: null,
  isAuthenticated: false,
  login: (user, token) => set({ user, token, isAuthenticated: true }),
  logout: () => set({ user: null, token: null, isAuthenticated: false }),
}));
```

> `persist` 미들웨어로 토큰을 localStorage에 저장하는 경우, 그 선택과 XSS 위험을 9절(프론트엔드 보안)에 기재합니다.

## 9. 프론트엔드 보안

> 점검·조치 결과는 `9. 보안점검서.md` 에 기록합니다.

- **XSS 방지**: `dangerouslySetInnerHTML` 사용 여부, 사용 시 sanitize 방식 (AI 응답·채팅 렌더링 포함)
- **토큰 저장**: 저장 위치(메모리 / localStorage / HttpOnly 쿠키)와 선택 근거
- **토큰 만료 처리**: Axios 인터셉터에서 401 → Refresh → 재요청 흐름
- **보호 라우트**: ProtectedRoute 구현 (최종 인가는 서버에서 수행함을 명시)
- **의존성 점검**: `npm audit` 결과 및 조치
- **에러 노출**: 서버 에러 메시지를 사용자용 문구로 변환
